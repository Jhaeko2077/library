# Biblioteca Virtual · I.E. 40129 "Manuel Veramendi e Hidalgo"

Portal web de **biblioteca virtual escolar**, organizado por áreas curriculares para que los estudiantes encuentren material de estudio fácilmente.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![Google Analytics](https://img.shields.io/badge/Google_Analytics-E37400?logo=googleanalytics&logoColor=white)

## Áreas

| Página | Área |
|---|---|
| `indexComunicacion.html` | Comunicación |
| `indexMatematica.html` | Matemática |
| `indexCyT.html` | Ciencia y Tecnología |
| `indexSociales.html` | Ciencias Sociales |
| `indexIngles.html` | Inglés |
| `indexEPT.html` | Educación para el Trabajo |
| `indexEducacionFisica.html` | Educación Física |

## Características

- Portada con insignia institucional y acceso visual a cada área.
- Recursos en ventanas modales.
- Medición de visitas con **Google Analytics 4** y **Google Tag Manager**.
- Sitio estático: no necesita backend y se puede publicar en GitHub Pages, Netlify o cualquier hosting.

## Ver localmente

Abre `index.html` en el navegador o sirve la carpeta:

```bash
npx serve .
```
